# 输入框 Placeholder 设计

## 目标

为登录弹窗和关键词标签编辑器增加简洁的输入提示，不改变现有标签、自动填充、校验、分隔符解析和保存行为。

## 文案

- 用户名输入框：`请输入用户名`
- 密码输入框：`请输入密码`
- 关键词标签输入框：`输入关键词`

关键词输入框上方已显示完整的分隔符说明，因此 placeholder 不重复说明 `|`、`;`、英文逗号、换行和 Enter。

## 实现与验证

直接设置现有 input 元素的 `placeholder` 属性，不新增组件或样式。自动化测试分别验证登录输入框和标签输入框的 placeholder，并运行完整规则测试、语法、格式及差异检查。
